# ระบบสรุปคอมเมนต์แจ้งปัญหา
ศูนย์ปฏิบัติการน้ำท่วม กทม. · สำนักงานเขตทวีวัฒนา

รวบรวมคอมเมนต์จากโพสต์ Facebook (CSV จาก extension "Comments Exporter") คัดเฉพาะเรื่องแจ้งปัญหา/ขอความช่วยเหลือ
แยกหมวดตามภารกิจฝ่าย จัดความเร่งด่วน ดึงสถานที่ แล้วแสดงเป็น Dashboard และรายงาน

โค้ดชุดเดียวรันได้ 2 แบบ
| | ฐานข้อมูล | เข้าถึงได้จาก |
|---|---|---|
| **ออนไลน์ (Vercel)** | Supabase Postgres (`DATABASE_URL` หรือ `POSTGRES_URL`) | ทุกที่ รวมถึงมือถือ |
| **ในเครื่อง** | SQLite `data.sqlite3` | เครื่องนี้ และเครื่องในวงแลนเดียวกัน |

## ใช้งาน (ผู้ดูแล)
1. หน้า **โพสต์ & นำเข้า** → เพิ่มลิงก์โพสต์ Facebook ที่ต้องติดตาม
2. เปิดโพสต์ → กด extension Comments Exporter → Export CSV
3. กด **นำเข้า CSV** ที่โพสต์นั้น (อัปโหลดซ้ำได้ ระบบเพิ่มเฉพาะคอมเมนต์ใหม่ · โพสต์ที่ไม่ได้ดึงเกิน 6 ชม. จะขึ้น ⚠)
4. หน้า **ตรวจทาน**: ยืนยัน/แก้หมวด/ตัดทิ้ง · ไล่ดูแท็บ "ไม่เข้าหมวด" และ "ต้องเปิดดู"
5. หน้า **รายการปัญหา**: อัปเดตสถานะ (บันทึกทันที) และหมายเหตุการดำเนินการ
6. หน้า **Dashboard**: ส่งออก *สรุปผู้บริหาร* (ไม่มีชื่อ) หรือ *รายงานปฏิบัติการ* (ภายใน มีชื่อ/ลิงก์)

## ติดตั้งบน Vercel + Supabase
1. สร้างโปรเจกต์บน Vercel จาก repo นี้ (Framework: Other)
2. Vercel → Storage → เพิ่ม **Supabase** (ตั้ง `POSTGRES_URL` ให้อัตโนมัติ)
   หรือใส่ `DATABASE_URL` เอง = Connection string แบบ **Transaction pooler** (พอร์ต 6543) จาก Supabase → Connect
3. ตั้ง Environment Variables `ADMIN_PASSWORD` และ `VIEWER_PASSWORD` (รหัสเริ่มต้น ใช้ครั้งแรกครั้งเดียว เปลี่ยนภายหลังในหน้า ตั้งค่า)
4. Deploy — ตารางถูกสร้างอัตโนมัติเมื่อมีคนเปิดครั้งแรก และเปิด Row Level Security ไว้ทุกตาราง
   (ข้อมูลอ่านผ่าน API สาธารณะของ Supabase ไม่ได้ ระบบนี้ต่อฐานข้อมูลตรง)

## รันในเครื่อง
- Mac: ดับเบิลคลิก `เปิดระบบ (Mac).command` · Windows: `เปิดระบบ (Windows).bat` · หรือ `python3 run_local.py`
- ครั้งแรกจะแสดงรหัสผ่านผู้ดูแล/ผู้ดูบนหน้าจอ ไม่ต้องติดตั้งอะไรเพิ่ม (ใช้ Postgres ในเครื่องได้ถ้าตั้ง `DATABASE_URL` และติดตั้ง `pip install -r requirements.txt`)

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `core/classifier.py` | หมวด keyword เริ่มต้น เกณฑ์ความเร่งด่วน และการดึงสถานที่ |
| `core/db.py` | ฐานข้อมูล (SQLite/Postgres) การนำเข้า การจับคู่โพสต์ สถิติ ส่งออก รหัสผ่าน/session |
| `core/server.py` | API และสิทธิ์ผู้ใช้ 2 ระดับ |
| `api/index.py` | จุดเข้าของ Vercel |
| `public/` | หน้าเว็บ |
| `run_local.py` | รันในเครื่อง |
